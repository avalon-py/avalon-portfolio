What the results show

Measured on 1,060 held-out videos, the newest 10% by publish date. The score is Spearman rank correlation between predicted and actual performance (1.0 would be a perfect ranking).

Short version: the model ranks videos modestly better than chance (about 0.33). Most of that comes from channel-level features, and the thumbnail and title add roughly +0.04.

Visual tabular features did not help

Face detection, text-in-image and colour statistics showed no measurable benefit over five seeds, so I removed all seven from training and serving.

How to read this

A correlation near 0.3 is useful for comparing options for one video, not for forecasting exact views.

The subscriber count is the channel's current one, not the count at publish time, which adds noise.

The promotion test slice moves with each retrain, so those points are not a fixed benchmark.
